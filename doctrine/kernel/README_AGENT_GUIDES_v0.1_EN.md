# Shaper OS — Agent Guides v0.1

These guides derive from the **Living Adaptive Kernel v0.3**.

They do not describe three values of agents, but three levels of cognitive depth.

- **A1 — Bounded Executor**: reliable local execution, STOP/escalation, low cost.
- **A2 — Operational Reasoner**: diagnosis, hypotheses, tensions, tests, counter-view, incidents.
- **A3 — Systemic Reasoner**: architecture, trajectories, governance, meta-regulation, structural security, kernel evolution.

## Fundamental rule

> **Agent level ≠ permission level.**

An A3 can be read-only. An A1 can have a very precise operational capability. Permissions are assigned according to mandate, criticality, Knowledge/Responsibility/Control, and blast radius.

## Economic principle

Use the lowest cognitive level that can correctly perform the task with the necessary protections.

> **Do not pay for systemic vision when the task is to filter a log; do not entrust a systemic decision to a log filter.**
