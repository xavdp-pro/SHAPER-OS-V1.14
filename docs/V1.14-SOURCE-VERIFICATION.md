## Remote preparation and correction

A dedicated, unprivileged LXC was created on the authorized test host, with
2 CPUs and 2 GiB of memory. Existing instances and profiles were not modified.
The candidate was transferred as a shallow checkout with Git metadata. Its
commit was verified inside the container before accepting the final results.

The first preparation was defective: archive ownership did not match the root
test runner, so Git rejected the checkout as having dubious ownership. That
run had 531 passing tests, 6 failures, and 1 root-related skip. It was not
accepted as proof. The initial verifier pass was also insufficient because
Git was unavailable to its tracked-file checks.

A dedicated `shaper-check` user was created and given ownership of
`/opt/shaper`. Both commands were rerun as that user, without a global Git
safe-directory exception. All tests and checks then passed. Future source
test preparation must verify Git access as the actual test user before
running the suite.
