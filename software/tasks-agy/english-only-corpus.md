# Task — put the hard-case corpus into English

## The rule

In this repository **everything produced is in English**: code, comments,
variable names, documentation, generated reports, error messages. French is
reserved for spoken conversation with the maintainer and must not appear in any
file.

`software/test-corpus/` currently violates this. Three files carry French:

| File | What it is |
| :--- | :--- |
| `measure.mjs` | the measurement script — comments, console output, and the Markdown it generates |
| `MESURE.md` | the report, generated by that script |
| `README.md` | the corpus documentation |
| `generate_corpus.py` | check it too |

## What to do

Translate to clear, idiomatic technical English. This is a rewrite of the
prose, not a word-for-word substitution: an English reader must find it
natural.

**`measure.mjs` matters most.** It emits the report, so translating `MESURE.md`
by hand is pointless — fix the generator, then re-run it so the report is
regenerated from the corrected source. The measured numbers must not change:
100 % on `00-sources`, 0 % on the rasterised categories, 0 crashes, 37 cases.

Rename the report to `MEASUREMENT.md` and delete the old `MESURE.md`. Keep the
script's filename as it is — other things may point at it.

## What not to touch

* The `.verite.txt` ground-truth files: their content is document text, not
  prose of ours. Leave them exactly as they are, including their names.
* The measured values. If a number moves, you broke something — say so instead
  of adjusting the number.
